# ARCHIVE ◈ Minimalist Notepad

ARCHIVE is a refined, browser-based minimalist notepad designed for focused writing and organized thought. It combines a clean, serif-heavy aesthetic with functional tools like checklists, file attachments, and a robust tagging system.

Built with a "privacy-first" mindset, all data is stored locally in your browser's `localStorage`, ensuring your notes stay on your machine.

## Features

-   **Checklist Mode:** Integrated task management with progress bars. Toggle between prose and tasks seamlessly.
-   **Local Persistence:** Uses `localStorage` to keep your data between sessions without needing a backend.
-   **Smart Tagging:** Organize entries with tags and filter your library with a single click.
-   **Attachments:** Support for images and documents (up to 5MB).
-   **Adaptive Themes:** Fluid switching between "Soft Light" and "Deep Dark" modes.
-   **Responsive Design:** Optimized for both desktop precision and mobile quick-capture.
-   **Word & Character Count:** Real-time tracking of your entry length.

## Getting Started

Since ARCHIVE is built with standard web technologies, there is no installation required.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/raniicodes/archive-notepad.git
    ```
2.  **Open the app:**
    Simply open `index.html` in any modern web browser.

## Built With

-   **HTML5** - Semantic structure.
-   **CSS3** - Custom properties (variables), Flexbox, and Grid.
-   **Vanilla JavaScript** - State management and DOM manipulation (No external frameworks).
-   **Google Fonts** - *DM Serif Display*, *DM Sans*, and *DM Mono*.

## Project Structure

-   `index.html` - The core structure and view containers.
-   `style.css` - Visual styling, theme tokens, and responsive breakpoints.
-   `script.js` - Logic for state, view switching, and data persistence.
